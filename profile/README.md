# NixOS: The Declarative System — the book's repositories

This organization hosts the repositories of the book *NixOS: The
Declarative System*. The book stands on its own; these repositories
are there for the day you want to compare, recover a stray file, spare
yourself a long stretch of typing or find a command again.

- **The chapters' projects**: `tomate`, `sentinelle`, `pilotage` and
  `carnet`, what the book has you clone, build or monitor, at the
  exact versions it prints.
- **The commands**: `snippets`, the command blocks of each chapter, in
  the order of the text and spelled out in full, ready to copy line by
  line, never to run in one go.
- **The configuration**: `companion`, the `/etc/nixos` you build, one
  commit per commit printed in the book, a tag at the end of each
  chapter. Enough to compare yours against, or to copy a long file
  from rather than typing it. The repository itself is not meant to be
  deployed as is: its keys and its hardware observations are those of
  our machines.

Without the book, these repositories read like a skeleton: the book
carries the context, the progression and the explanations.

A typo in a snippet, a problem with a project's code? Open an *issue*
on the repository concerned: your report will help the readers who
come after you.

**This project is independent.** It is neither affiliated with nor
endorsed by the NixOS Foundation or the NixOS community project;
"NixOS" is used here only to name the operating system the book is
about. Official site of the community project:
[nixos.org](https://nixos.org).
